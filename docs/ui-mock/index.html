02 人間のトークン チケットで開けないときだけ出る入力

Mac のターミナルで touryou ui を実行すると（Claude Code では /touryou:ui）、貼り付けなしで開けます。使えないときは、人間のトークンのファイルの中身を貼り付けてください。トークンはこのページのメモリにだけ置き、保存しません。

子の権限の規則

根の方針の規則です。「設定」は設定ファイル（config.json）の値、「実行中」は、いま足した規則です（daemon を起動し直すと、設定の値に戻ります）。deny は allow・ask より強く、ask に当たるツールの承認は、人間だけができます。

設定Bash(rm -rf:*)

設定Bash(git push:*)
