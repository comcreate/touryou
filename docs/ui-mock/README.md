# 状態画面 モック（Issue #236 第 1 段階）

`touryou ui` で開く状態画面を大きく作り直すための、**静的なモック**です。人が見て直すためのもので、本番のコード（`packages/` 以下）は変えていません。

## 開き方

ブラウザで `docs/ui-mock/index.html` を開きます（ファイルをそのまま開くだけ。サーバーは要りません）。

- 外部の通信・外部のフォントはありません（HTML・CSS・インライン SVG と、明暗を切り替える数行の script だけ）。
- 上のバーの「◐ 明暗」で、OS に合わせる → 明るい → 暗い と切り替わります。OS の設定（`prefers-color-scheme`）にも従います。
- 画面の組み方は見本（`ref/sample.html`）どおり、上のバー＋3 列（あなたの番・やり取りの図・作業のようす）で、画面全体はスクロールせず、列の中だけスクロールします（900px 以上）。3 列の後ろに全面の背景が見えます。
- 3 列に出ない部品（接続切れ・トークン入力・確認の欄・設定の窓・管理など）は、同じページの下の「部品の見本帳」に並べています（上の歯車を押すと、設定の窓へ移ります）。
- 900〜1279px は、左に「あなたの番」、右に「図（上）＋作業のようす（下）」。1280px 以上は 3 列。899px 以下は 1 列で、下のタブ（出番／図と作業）で切り替えます。
- スマホの幅（400px）は、ブラウザの幅を狭めるか、開発者ツールの端末表示で確かめます。
- 設定の窓の「動きを止める」を入れると、背景と線の動きが止まります。OS の「視差効果を減らす」でも止まります。
- 画面の値はすべてダミーです（実際のトークン・パス・ID は書いていません）。

## 見本から取り入れたこと

見た目の方針（`ref/sample.html`）:

- **配色の語**: 柿（あなたの出番・答え待ち）・松（動いている）・朱（失敗）・黄（止まっているかも）・藍（上り・リンク・焦点）。明暗それぞれに値を持ち、状態は色だけでなく「▶ ● ✓ ✕ ‖」の記号と文字でも示します。
- **すりガラスの面**: 上のバー・カード・作業の札・設定の窓などは、半透明の面に `backdrop-filter: blur`、細い縁、淡い影。
- **文字**: 本文 15px・行間 1.7。見出しは等幅で字間を広げた小さな札（`01 接続と通知` など）。関係図の札も等幅。
- **カードの形**: 角丸 8〜14px。状態の帯（左の太い線・動いているカードの緑の見出し）。上の状態の札（chip）は丸薬の形。
- **関係図**: 左が親、右が子。親の右に細いバー、線ごとの出入口の点。折れ線の角を丸め、種類ごとの色と、「↑ 判断 3 分前」の札を線の上に置く。新しいほど濃く太く、古いほど薄く細く。送ったが届いていない線は破線を流す。
- **余白とタッチ**: 押せるものは 44px 以上。スマホは 1 列。
- **画面の組み方**: 上のバー＋3 列、列の中だけスクロール、各列に窓の見出しとタブ、スマホは下のタブ 2 つ。
- **答えのボタン**: カードの中の答えのボタンは、横幅いっぱいの大きいボタン（高さ 48px、広いときは横に等分）。

全面の背景（`ref/architect_backgrounds.tsx`）:

- ブループリントの **2 段の方眼**（細い方眼 24px・太い方眼 120px。見本は 5 倍の比）と、太い方眼の交点の **小さな十字**。
- **大工・設計道具の輪郭 6 種**（差し金・コンパス・金槌・のこぎり・のみ・鉛筆）。見本どおりの色の割り当て（真鍮・青・テラコッタ・緑・紫・珊瑚）で、明暗で色を変える。シェーダーの距離関数を、インライン SVG の `<symbol>` に置き換えた。
- **光の塵**（小さな点が、ゆっくり瞬く）。
- 周辺をなじませる **ビネット**（中心が明るく、縁が背景色に溶ける）。
- 明は製図用紙の灰白、暗は深い藍の地。

## 取り入れなかったこと

- **React・WebGL・canvas**: 背景は依存なしの静的な SVG と CSS にした。シェーダーの動き（等角投影の傾き・流れる方眼・道具の回転と浮遊）は、静止した方眼と、ごくゆるい平行移動（120 秒）だけにした。文字を邪魔しないことと、動きを止める設定を優先したため。
- **sample.html のオーロラ（canvas のぼかし）**: 全面の背景は architect_backgrounds.tsx を使う指示なので採らない。
- **sample.html の見本用の操作**（接続を切ってみる・案の一覧）と、画面の言語・設定の保存、関係図のドラッグ・ズームの動き: 見た目だけを置いた（ボタンは置いてあるが、押しても何も起きない）。
- **見本の仮の言葉**（注文画面・支払い方法など）は、そのままダミーとして使った。

## 文字を読みやすくするための決め

- 面は 2 段。**窓の枠**（3 列の外側・上のバー・見本帳の台）は、背景がうっすら見える半透明（明 72%・暗 80%）で、弱いぼかしをかけます。**文字を載せる札・カード・窓の見出しとタブ・図の盤**は、ほぼ不透明（93%・92%）で、方眼や道具が文字の下に出ません。
- 窓の枠の上に直接載る文字は、補足の短い文（`lead`・`note`）だけ。そこでも、道具の色の上で文字の色が 4.5:1 を切らないよう、暗は窓の枠を濃くしています。
- 背景の道具は、明で 50%・暗で 55% の濃さ。縁はビネットで背景色に溶かします。
- 道具の線と塗りは、`<symbol>` の属性（`fill`・`stroke="currentColor"`）で直接指定しています。`<use>` が作る複製には、外側の `.bg` から始まるセレクタが届かず、黒の塗りが薄まって灰色に見えるため（レビューで指摘）。
- 文字の色は、面の色に対して次の値です（手計算の目安。色の検証の道具では確かめていません）。

| 組み合わせ | 明 | 暗 |
| --- | --- | --- |
| 本文（ink） | 約 16:1 | 約 15:1 |
| 補足（ink2） | 約 7:1 | 約 8:1 |
| 柿・朱・松・黄・藍（文字として） | 5〜7:1 | 7〜9:1 |
| 押すボタン（柿の地に白・暗は黒） | 約 5:1 | 約 9:1 |

関係図の線の色は、飾りでなく、札の文字と記号でも同じ内容を示しています。

## 守っていること

- **キーボードの焦点**: 3px の藍の輪郭（`:focus-visible`）。関係図の箱は Tab で届き、焦点で縁が太くなる。「本文へ移る」のリンクあり。窓のタブは左右の矢印・Home・End で移れる。
- **関係図の文字**: 札・箱の文字は図の座標で 12.5〜14px。幅 1440px の中央の窓では、ほぼ等倍（約 1.05 倍）で出る見込み（実機の計測はしていない）。
- **横スクロール**: 本文・窓・カードに `min-width:0`・`minmax(0,1fr)`・`overflow-wrap:anywhere` を入れている。幅 375px・400px の実機表示は、このモックの作成時には確かめていない（見る人が確かめる）。
- **動き**: `prefers-reduced-motion` と、設定の「動きを止める」で、接続の丸の呼吸・破線の流れ・背景の動きを止める。
- **読み上げ**: 状態は文字でも示し、矢印には `aria-label`（上り・下り）、図には `role="group"` とラベル。
- **明暗**: `prefers-color-scheme` と、明暗の手動の切り替え（`data-theme`）の両方。

## 次の段階

ブラッシュアップのあと、この見た目になるように、`packages/daemon/src/api/ui-assets.ts` と `packages/daemon/src/ui/*` を直します。直すときの注意（モックでは扱っていないこと）:

- CSP が `'self'` だけを許すため、背景の SVG は、インラインではなく別のファイル（`/ui/` の配信物）にするか、CSS の中で作る形が要る。
- インラインの `<script>`・`<style>` は置けない。モックの明暗の切り替えは、本番では既存の `theme-light`・`theme-dark` のクラスの仕組みを使う。
- 描画は `textContent` と `createElement` だけ（`ui-assets.test.ts` の走査）。
