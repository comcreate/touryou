# 紐付けが外れた子には報告の手段がなく、拒否されると自分で原因を探って範囲違反になる

## 現象

2026-11-20、統括 orch-root の報告です。

- 子が `SendMessage` で root に報告しようとすると、フックが「ツール SendMessage は、このノードでは使えない」と拒否します。
- 紐付け前は touryou の道具も使えないので、子には報告の手段がありません。
- 道具が拒否されると、子が自分で原因を探りに行き、範囲外の `launchd status` を試して範囲違反になりました（node-69aa・node-8564）。

## 期待する動き

1. 紐付け前（または外れたとき）でも、「紐付けが外れた」と親に知らせる最小の手段を用意する。
2. 拒否の文に、「自分で試さず、報告して待つ」を入れる。
3. `touryou:child` の手順にも、同じ案内を書く。
