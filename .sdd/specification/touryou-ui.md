# 1. 背景

利用者が承認した「第 5 弾の最終提案」（静的な見本）の見た目に、本番の状態画面（`touryou ui`）を寄せる。見本は作り物のデータだけで動く静的な HTML であり、本番のコードは変えていない。

本書は、寄せたあとの画面が満たす振る舞いと、確かめ方（受け入れ基準）を定める。daemon の API とデータの形（`packages/core/src/ui-view.ts` の表示モデル）は変えない。

# 2. 位置づけと既存の仕様との関係

- 種別は「新機能（小）」。既存の機能（状態画面）の中の、描画の層だけの変更で、PRD の新規作成は要らない。理由は [design-draft.md](../task/ui-status-screen-look/design-draft.md) の 1 節にある。
- [touryou_spec.md](./touryou_spec.md) 5.6 節の画面の構成（#89）と、本書の次の点は食い違う。**どちらを正にするかは人間の判断**で、本書は、決まるまで 5.6 節を書き換えない（PRD も同じ）。

| 5.6 節の記述 | 本書（見本）の姿 |
|:--|:--|
| 関係図は「根を左に置く横向きの木。1 本の枝に 2 本の道を並べ、上の道が上り（矢印は左向き）、下の道が下り（矢印は右向き）」 | 親ごとに細いバーを置き、線ごとに別の点から直角に折れる線を引く。向きは札の文字「↑」「↓」で示す |
| いちばん上に「いまあなたがすること」。大きな数と一覧 | 左の窓「あなたの番」の中のタブ「判断・答え待ち」。件数は窓の見出しとタブのバッジだけ |
| 作業ごとのまとまり（カードの一覧を 1 画面に並べる） | 右の窓「作業のようす」の中の 2 つのタブ「選んだ作業」「作業の一覧」 |
| 「管理」の欄をたたんで置く | 見本には無い。置き場は未決（design-draft 6 節） |

| UI_011 | スマホは 1 列で、下の切り替え（出番／図／作業）で窓を選ぶ。いまの窓に `aria-current="page"`。操作できる部分は 44px 以上 | index.html の 1 節 |

| UI_015 | 設定の窓は「動きを止める」「明るさ（自動・ライト・ダーク）」「言語」の 3 つ。閉じたら、開いたボタンに焦点を戻す | proposal-final.html の設定の窓 |

# 4. 本番で守る点（見本から持ち込まないもの）

| ID | 内容 |
|:--|:--|
| UI_101 | 見本の作り物のデータは持ち込まない。本番は、表示モデル（`uiViewOf`）の値だけで描く。集計は本番の値で、折りたたまずに並べる（UI_007）。「状態の見本」「接続を切る見本」は、見本の中の作り物の操作なので、本番にそのまま置くかは未決（design-draft.md 6-8） |
| UI_102 | 描画の安全は変えない：文字は `textContent` と `createElement` だけで描く。`innerHTML`・`style` 属性・外の資源・CDN・外部フォントを使わない。CSP は同じ配信元のものだけを許す |
| UI_103 | 設定の保存先は localStorage の `touryou.ui.settings`（キー `still`・`theme`・`lang`）のまま。見本の `tp5.` の接頭辞は持ち込まない。localStorage が使えなくても動く |
| UI_104 | daemon の API・表示モデル（`UiNode`・`UiFlow` など）・上限（`UI_LIMITS`）を変えない |
| UI_105 | 「統合が受け取った記録」が無い間は、子 → 親の「届いた」を分からないと示す（touryou_spec.md 5.6 節）。見本の線の段もこの規則で描く |

# 6. 未確認・未決

- 本書は、コードと見本の**読み取り**だけに基づく。ブラウザでの表示・動作は、見本も本番も確かめていない。
- 差分の整理と、決めてほしい点（選択肢と推奨）は [design-draft.md](../task/ui-status-screen-look/design-draft.md) の 5・6 節にある。
- PRD（FR_021・IR_003）に矛盾がないかは、全文を読み切れていない。矛盾が見つかったら、PRD は書き換えず、人間に報告する。
